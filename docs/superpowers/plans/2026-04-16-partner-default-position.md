# Partner Default Position Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users set a default position per partner that auto-fills when that partner is added to an encounter form.

**Architecture:** `SQLPartner` gains `defaultPositionTypeId: UUID?`. Migration 13 adds the column. `PartnerDetailView` exposes a picker in the Relationship section (edit and view mode). `EncounterFormView.togglePartner()` pre-fills `partnerPositionTypeIDs` from the partner's default when they're selected.

**Tech Stack:** Swift 5.9+, SwiftUI, SQLiteData (GRDB)

## Task 3: Pre-fill Position in EncounterFormView

**Files:**
- Modify: `Fuckify/Features/Encounter/Views/EncounterFormView.swift`

When a partner is added to `selectedPartnerIDs`, check if they have a `defaultPositionTypeId` and pre-fill `partnerPositionTypeIDs`.

- [ ] **Step 1: Update `togglePartner()` to pre-fill default position**

Read the current `togglePartner()` method. Replace it with:

```swift
    private func togglePartner(_ partnerID: UUID) {
        if selectedPartnerIDs.contains(partnerID) {
            selectedPartnerIDs.remove(partnerID)
            partnerPositionTypeIDs.removeValue(forKey: partnerID)
            partnerOrgasms.removeValue(forKey: partnerID)
        } else {
            selectedPartnerIDs.insert(partnerID)
            // Pre-fill default position if the partner has one set
            if let partner = allPartners.first(where: { $0.id == partnerID }),
               let defaultPositionId = partner.defaultPositionTypeId {
                partnerPositionTypeIDs[partnerID] = defaultPositionId
            }
        }
    }
```
